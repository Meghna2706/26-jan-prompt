# 🌾 Mandi AI Assistant  
### Multilingual Fair Price & Negotiation Platform

Mandi AI Assistant is a multilingual, voice-enabled AI platform designed to help farmers and local traders discover **fair market prices**, understand **market trends**, and **negotiate confidently** without language or technical barriers.

The platform focuses on transparency, accessibility, and real-world usability for India’s agricultural ecosystem.

---

## 🚀 Features

- 🌐 **Multilingual Support**  
  Supports Indian languages like Hindi, Telugu, Tamil, Bengali, Marathi, and English.

- 🎙️ **Voice Input Enabled**  
  Users can speak instead of typing, making it accessible for non-technical users.

- 📊 **Fair Price Estimation**  
  AI generates a fair price range based on:
  - Location  
  - Quantity  
  - Market demand  
  - Seasonality  

- 📈 **Market Trend Insights**  
  Shows daily trends and short-term movements to help users decide the best time to sell.

- 🤝 **AI Negotiation Assistant**  
  Helps users:
  - Evaluate buyer offers  
  - Suggest counter-prices  
  - Avoid unfair deals  

---

## 🖥️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **AI Logic**: Pricing & negotiation intelligence  
- **Voice Support**: Browser Speech APIs  
- **Design**: Mobile-friendly & farmer-centric UI  

---

## 🧭 How It Works

1. User selects a preferred language  
2. Enters or speaks:
   - Crop name  
   - Quantity  
   - Location  
3. AI analyzes market conditions  
4. Platform displays:
   - Fair price range  
   - Market trends  
   - Negotiation suggestions
