# 🌾 Mandi AI Platform
### Multilingual AI-Powered Agricultural Marketplace

Mandi AI Platform is a comprehensive multilingual web application designed to empower farmers and traders in India with AI-driven price discovery, market analytics, negotiation assistance, and voice-enabled commands. The platform provides real-time market insights, fair pricing recommendations, and strategic negotiation support across 6 Indian languages.

## 🧭 How to Use

### Basic Flow
1. Select your preferred language from the dropdown
2. Navigate between pages using the navigation bar
3. Use voice button (🎤) to give voice commands
4. Fill forms and click submit buttons

### Price Discovery
1. Go to Price Discovery page
2. Select a commodity (Wheat, Rice, Cotton, Sugarcane)
3. Enter quantity in kilograms
4. Select your region (29 Indian states available)
5. Click "Discover Price" to see recommendations

### Negotiation Assistant
1. Go to Negotiation page
2. Select commodity
3. Enter buyer's offer price
4. Enter your expected price
5. Enter quantity
6. Click "Get Negotiation Tips" for AI suggestions

### Voice Commands
1. Click the voice button (🎤)
2. Speak commands like:
   - "Dashboard" / "Price" / "Analytics" / "Negotiation" / "Profile"
   - "Select wheat" / "Set quantity 500kg"
   - "Get tips" / "Discover price"
3. System responds with voice feedback
