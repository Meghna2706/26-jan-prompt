# Voice Recognition Commands - Mandi AI Platform

## How to Use Voice Recognition

1. Click the **🎤 Voice** button in the top-right corner
2. The button will turn red and say "Listening..."
3. Speak your command clearly
4. The system will process your command and respond

---

## Navigation Commands

Say any of these to navigate to different pages:

- **"Dashboard"** → Go to Dashboard
- **"Price"** or **"Price Discovery"** → Go to Price Discovery
- **"Analytics"** or **"Market Analytics"** → Go to Market Analytics
- **"Negotiation"** → Go to Negotiation Assistant
- **"Profile"** → Go to User Profile

## Tips for Best Results

1. **Speak clearly** - Enunciate your words properly
2. **Use English** - Commands work best in English
3. **Wait for response** - Let the system finish processing before speaking again
4. **One command at a time** - Say one command per voice activation
5. **Check microphone** - Ensure your microphone is working and not muted

---

## Troubleshooting

**Voice recognition not working?**
- Check if your browser supports Web Speech API
- Ensure microphone permissions are granted
- Try refreshing the page
- Use Chrome or Edge for best compatibility

**Command not recognized?**
- Speak more clearly
- Use exact command words
- Try again after the system responds
